# 🌅 Automated AI Morning Briefing

An automated **AI-powered morning briefing system** built with **n8n, Open-Meteo, REST Countries API, OpenRouter, Supabase, and Gmail**.

The workflow automatically collects the daily weather for **Rawalpindi**, selects a **country of the day**, generates a short AI-powered briefing, saves the result to a Supabase database, and sends the briefing to email.

---

## 📌 Project Overview

The goal of this project is to automate a personalized morning briefing without manually collecting information every day.

The automation performs the following tasks:

1. 🌤️ Gets the current weather in Rawalpindi.
2. 🌍 Selects a country of the day.
3. 📊 Retrieves country information such as capital and population.
4. 🤖 Uses an AI model to generate a friendly 3-sentence briefing.
5. 🗄️ Saves the briefing data to Supabase.
6. 📧 Sends the final briefing through Gmail.

---


---

## ⚙️ n8n Workflow Nodes

### 1. Schedule Trigger

Starts the automation automatically according to the configured schedule.

The workflow is configured to run in the morning.

---

### 2. Get Rawalpindi Weather

Uses the **Open-Meteo API** to retrieve weather information for Rawalpindi.

The workflow collects information such as:

* Temperature
* Feels-like temperature
* Humidity
* Wind speed
* Weather condition

---

### 3. Get Country

Uses the **REST Countries API** to retrieve information about the selected country.

The workflow extracts:

* Country name
* Capital
* Population

The country changes according to the configured daily selection.

---

### 4. Generate AI Briefing

The collected weather and country information is sent to an AI model through **OpenRouter**.

The AI generates a short and friendly morning briefing.

The generated briefing follows these rules:

* Exactly 3 sentences
* Friendly and useful
* Mentions the weather
* Mentions the country of the day
* Does not use bullet points
* Does not mention that it is generated by AI

---

### 5. Build Final Briefing

This node combines the weather, country information, and AI response into one structured JSON object.

Example structure:

```json
{
  "briefing_date": "2026-09-07",
  "city": "Rawalpindi",
  "temperature": 27,
  "weather": "Partly cloudy",
  "country": "Japan",
  "country_capital": "Tokyo",
  "country_population": 125000000,
  "ai_briefing": "Good morning! ..."
}
```

---

### 6. Save to Supabase

The final briefing is stored in a Supabase table called:

```text
daily_briefings
```

The database stores:

| Field                | Description           |
| -------------------- | --------------------- |
| `id`                 | Unique record ID      |
| `created_at`         | Record creation time  |
| `briefing_date`      | Date of the briefing  |
| `city`               | Weather location      |
| `temperature`        | Temperature in °C     |
| `weather`            | Weather condition     |
| `country`            | Country of the day    |
| `country_capital`    | Country's capital     |
| `country_population` | Country population    |
| `ai_briefing`        | Generated AI briefing |

The database schema is available in:

```text
database/schema.sql
```

---

### 7. Send Morning Briefing

The final briefing is sent through Gmail as an HTML email.

The email contains:

* AI-generated morning briefing
* Temperature
* Country of the day
* Capital
* Date

## 🚀 How to Use

### 1. Install / Access n8n

Create an n8n workspace or run n8n locally.

### 2. Import the Workflow

Download:

```text
workflow/morning-briefing-workflow.json
```

and import it into n8n.

### 3. Configure Credentials

Configure your own credentials for:

* REST Countries API
* OpenRouter
* Supabase
* Gmail

### 4. Create the Supabase Table

Run the SQL from:

```text
database/schema.sql
```

inside your Supabase SQL Editor.

### 5. Test the Workflow

Run the workflow manually from n8n.

Verify that:

* Weather data is retrieved.
* Country information is retrieved.
* AI briefing is generated.
* Data is saved to Supabase.
* Email is received successfully.

### 6. Activate the Workflow

Once everything has been tested, activate the n8n workflow so the scheduled automation can run automatically.
